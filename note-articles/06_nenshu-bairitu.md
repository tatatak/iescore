# 銀行が「審査OK」を出しても、返せるとは限らない——年収倍率の正しい使い方

「年収の5〜7倍が目安って聞いたから、年収600万円なら3,000〜4,200万円まで借りて大丈夫ですよね？」

住宅購入を検討中の方から、こういう質問をよく受けます。目安として「年収倍率」を知っている人は増えました。でも、その数字の意味を正確に理解している人は、意外と少ないんです。

今日は「年収の何倍まで借りていいのか」という問いを、もう少し深掘りして考えてみます。

---

## 「5〜7倍」という数字はどこから来たのか

住宅金融支援機構が毎年発表している「フラット35利用者調査」によると、実際にマイホームを購入した人の年収倍率の平均は次のとおりです（2023年度）。

- **注文住宅**: 7.0倍
- **中古マンション**: 7.2倍
- **土地付き注文住宅**: 7.5倍

「5〜7倍」という数字は、実際に購入した人たちの平均値から来ています。つまり「これだけ借りても買っている人が多い」というデータであって、「これだけ借りれば安全」という意味ではありません。

---

## 「借りられる額」と「返せる額」は全然違う

ここが一番大事なポイントです。

銀行が住宅ローンの審査で見ているのは「年収倍率」ではなく、**「返済負担率」**です。返済負担率とは、年収に対してローン返済額が何%を占めるかを示す数字です。

多くの金融機関では、**年収の35%以内**であれば審査に通る設計になっています。

年収600万円の場合で計算してみましょう。

```
年収600万円 × 35% = 年間返済額 210万円
月々の返済額 = 175,000円
```

金利1.5%・35年ローンで計算すると、月17.5万円の返済ができる借入額はおよそ**4,600万円**になります。年収の約7.6倍です。銀行はこの金額まで貸してくれます。

でも、本当にそれだけ借りていいのでしょうか。

---

## 「知らなかった」：審査OKのラインと生活できるラインは別物

ここで多くの人が見落としているのが、**額面年収と手取り年収の差**です。

年収600万円の場合、手取りはおよそ460〜480万円（税金・社会保険料を引いた後）になります。

銀行の審査基準（35%）は**額面年収**に対して計算しています。一方、実際に家計をやりくりするのは**手取り**です。

**手取り年収480万円の25%以内**で計算すると——

```
480万円 × 25% = 年間返済額 120万円
月々の返済額 = 100,000円
```

同じ金利・返済期間で計算すると、借入額は**約2,700万円**。年収の4.5倍です。

銀行が「4,600万円まで貸せます」と言っても、生活に余裕を持って返せる額は「2,700万円」——この差が約2,000万円あります。

「審査に通ったから大丈夫」という油断が、長期間にわたる家計の苦しさにつながります。

## なぜ25%が目安なのか

月10万円の返済に対して、残りの月収で以下をまかなう必要があります。

- 食費・光熱費・通信費（生活費）
- 教育費（特に子どもがいる場合）
- 管理費・修繕積立金（マンションの場合、月2〜4万円）
- 固定資産税（年10〜20万円）
- 車の維持費・保険
- 老後の貯蓄・緊急時の予備費

住居費だけで手取りの35%を超えると、これらが綱渡りになります。収入が少し下がる（病気・育休・転職）だけで、家計が一気に苦しくなります。

変動金利を選ぶ場合は、「現在の金利で計算した返済額」ではなく、**金利が1〜2%上昇した場合の返済額**でも生活が成り立つかどうかを確認してください。
