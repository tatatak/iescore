# Note記事 → SNS発信 自動化メモ

記事を書いたあとの作業を自動化するスクリプトが2つあります。

---

## 1. Gemini画像プロンプト生成

```bash
npm run img <記事番号>
```

**やること**
- 記事のタイトルと本文からGemini用プロンプトを自動生成
- クリップボードにコピー
- gemini.google.com を自動で開く

**使い方の流れ**
1. ターミナルで `npm run img 42`（42は記事番号）を実行
2. Gemini が開くので Cmd+V で貼り付けて送信
3. 生成された画像を `iescore記事042_image.png` という名前で保存

---

## 2. X（Twitter）投稿スレッド生成

```bash
npm run tweet <記事番号>
```

**やること**
- 記事からXのスレッド（3ポスト分）を自動生成
- スレッド全文をクリップボードにコピー
- x.com/compose/post を自動で開く
- 検索ワード（悩んでいる人を探すため）を画面に表示
- 返信テンプレートを画面に表示

**使い方の流れ**
1. ターミナルで `npm run tweet 42` を実行
2. X が開くので Cmd+V で貼り付けて投稿
3. 画面に出た検索ワードをXの検索窓に入れて悩んでいる人を探す
4. 見つけた人に返信テンプレートを参考にリプライ

---

## セットで使う場合の手順

```bash
# 記事42を例に
npm run img 42    # → Gemini で画像生成
npm run tweet 42  # → Xで投稿
```

---

## 記事番号の調べ方

`note-articles/TOPICS.md` の「執筆済み」テーブルを参照。

ファイル名の先頭の数字が記事番号です（例: `11_hoseiyosan-kinri.md` → `11`）。

---

## 引数なしで実行した場合

```bash
npm run tweet   # note-articles/ の中で最新のmdファイルを使用
```
